# Maya Shadow Academy — Ready-to-Publish Static Website

## Included
- Responsive professional website
- Home / portfolio
- Courses
- Recorded classes
- Resources
- Services
- Buy / purchase section
- Contact section
- SVG logo and hero banner
- No server, database, passwords, or payment secrets in frontend code

## Publish on Render
Create a **Static Site** connected to this GitHub repository.
- Build command: leave blank
- Publish directory: `.`
- Branch: `main`

## Before launch
Replace placeholder links in `index.html`:
- course checkout/payment links
- recorded class links
- resource links
- YouTube URL
- WhatsApp URL
- email address
- prices

Never put payment gateway secret keys, admin passwords, JWT secrets, API private keys, or database credentials into this static website.
